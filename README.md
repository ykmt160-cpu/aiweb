# 미래의 나 홈페이지 전시관

바이블 쌤과 함께하는 인공지능 기초: 생성형 AI 활용수업
(Claude를 활용한 미래의 나를 소개하는 홈페이지 제작활동)

학생 HTML 작품을 반별로 모아 썸네일로 보여 주고, 클릭하면 바로 열어 볼 수 있는 정적 웹사이트입니다.
서버·DB·회원가입이 필요 없어서 무료 호스팅에 그대로 올릴 수 있습니다.

## 폴더 구조

```
exhibition/
├─ index.html      전시 사이트 (메인 소개 + 반별 갤러리)
├─ works.js        작품 목록 (update.py 가 자동 생성)
├─ update.py       works 폴더를 읽어 works.js 를 만드는 스크립트
└─ works/
   ├─ 1반/  홍길동.html   홍길동.png(선택, 썸네일)
   ├─ 2반/  ...
   ├─ 3반/
   ├─ 4반/
   └─ 5반/
```

## 작품 올리는 방법 (일괄 업로드)

1. 학생 파일을 `works/1반` ~ `works/5반` 폴더에 한꺼번에 복사합니다.
   파일 이름이 곧 카드에 표시되는 이름이 됩니다 (예: `김하늘.html` → 김하늘).
2. 썸네일을 쓰고 싶으면 같은 이름의 이미지를 옆에 둡니다 (`김하늘.png`, `.jpg`, `.webp` 가능).
   이미지가 없으면 HTML 페이지의 축소 미리보기가 자동으로 썸네일이 됩니다.
3. 작품 목록(`works.js`)을 만듭니다. 방법은 둘 중 하나입니다.
   - **파이썬이 있을 때**: 이 폴더에서 `python update.py` 실행 (설치할 패키지는 없습니다).
   - **파이썬이 없을 때**: `update.html` 을 브라우저로 열고 `works` 폴더를 선택한 뒤,
     `works.js 내려받기` 를 눌러 받은 파일을 `index.html` 옆에 덮어씁니다.
4. 폴더 전체(`index.html`, `works.js`, `works/`)를 웹에 올립니다.

폴더 대신 파일명 앞에 반을 붙여도 됩니다: `works/1반_홍길동.html`, `works/3-김철수.html`.
반을 알 수 없는 파일은 제외되고, 실행 결과에 목록이 표시됩니다.

## 웹에 공개하는 방법

- **GitHub Pages**: 저장소에 폴더를 올리고 Settings → Pages 에서 켜면 무료 주소가 생깁니다.
- **Netlify Drop** (app.netlify.com/drop): 폴더를 끌어다 놓으면 바로 배포됩니다.
- 학교 서버: 폴더를 그대로 복사하면 됩니다.

작품을 추가·교체할 때는 파일을 넣고 `update.py` 를 다시 실행한 뒤 다시 올리면 됩니다.

## 알아 두면 좋은 점

- 미리보기는 학생 페이지를 작은 창으로 실제 실행하는 방식이라, 작품이 많으면(수십 개 이상) 썸네일 이미지를 함께 올리는 편이 더 빠릅니다.
- 학생 작품은 격리된 창(sandbox)에서 열려서 전시관 페이지에 영향을 주지 못합니다.
- 인터넷의 외부 이미지·폰트를 쓰는 작품은 인터넷이 연결되어 있어야 온전히 보입니다.
- 메인 소개 문구와 진행 단계는 `index.html` 의 "수업 소개", "활동 진행 과정" 부분을 수정하면 됩니다.
- `works/` 안의 샘플 작품 4개는 테스트용이니 삭제하고 쓰세요.
